# Customer Segmentation using K-Means Clustering

This project uses the K-Means Clustering algorithm to group customers of a retail store based on their Annual Income and Spending Score.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Mall Customer Dataset

## Project Steps
1. Data Loading
2. Feature Selection
3. Elbow Method for optimal clusters
4. K-Means Clustering
5. Data Visualization

## Output
- Elbow Method Graph
- Customer Segmentation Graph
